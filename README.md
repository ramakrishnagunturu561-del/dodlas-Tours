## 💻 Technology Architecture
- **Pure Static Stack:** HTML5, CSS3, Vanilla JavaScript (ES6+)
- **Typography:** Google Fonts (*Cormorant Garamond*, *Cinzel*, *Plus Jakarta Sans*)
- **Icons:** Font Awesome 6.5
- **Zero Server Overhead:** 100% portable static codebase with zero database or backend runtime requirements. Ready for instant deployment on GitHub Pages, Netlify, Vercel, or standard cPanel web hosting.
